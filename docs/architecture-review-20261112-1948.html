Problem

The torrent lifecycle is a stringly-typed protocol spread over 17 UPDATE statements in two modules, so no interface owns legal transitions, retryability, or the import outcome vocabulary.

Solution

A torrent_ledger module exposes a TorrentStatus enum and guarded methods; callers ask for a transition and get a typed error when the source status disallows it.

Wins

  • • One lifecycle, seventeen writes
  • • Illegal transitions rejected locally
  • • Retryability owned by the ledger
  • • partial becomes reachable and tested
  • • Import outcome asserted once
